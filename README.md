# 달성 수학 10분 · 심화 문항

교재의 차시별 QR을 찍으면 그 차시 심화 문항이 태블릿에 열리고, 최종 답을 쓰면 바로 ⭕/❌로 채점됩니다.

- 사이트: https://oooalways1.github.io/2027-math10/
- 학년 폴더: `4-1/` (3-1, 5-1, 6-1은 준비 중)
- 차시 주소: `4-1/#07` 처럼 `#차시번호`
- QR 만들기: `python tools/make_qr.py 4-1` → `qr/4-1/07.png` …

## 새 학년 추가

1. `4-1/` 폴더를 복사해 `5-1/` 처럼 이름을 바꿉니다.
2. `index.html` 안의 `LESSONS` 문항 데이터와 `img/` 그림을 바꿉니다.
3. 맨 위 `index.html` 에서 그 학년 칸을 링크로 바꿉니다.
4. `python tools/make_qr.py 5-1` 로 QR을 만듭니다.
